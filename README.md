# Medical Health Report

Medical Health Report is a web application that helps users upload and manage medical reports in one place. It provides a simple interface for securely storing reports and viewing health-related information whenever needed.

## Features

* User authentication
* Upload and manage medical reports
* Secure access to personal records
* Clean and responsive interface
* Easy navigation

## Tech Stack

* TypeScript
* React.js
* Node.js
* Express.js
* MongoDB

## Installation

```bash
git clone https://github.com/praveen-gouraj/medical-health-report.git
cd medical-health-report
npm install
npm run dev
```

## Purpose

This project was built to learn full-stack development using TypeScript while creating a simple and secure platform for managing digital medical records.
